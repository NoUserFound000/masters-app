同步、備份同安裝

所有學習功能都可以離線用，唔使 AI。內容同進度存喺呢部機；GitHub 同步會用你私人 repo 拉內容、備份進度，同埋將你嘅練習答案交俾 Claude 寫回饋。

GitHub 同步

私人 repo

未設定。

點樣開 token
  1. 開 GitHub 新 token 頁（名、365 日到期、Contents 讀寫已預填）。
  2. Repository access 揀「Only select repositories」，只揀你嘅私人 repo。
  3. Generate，複製，貼喺上面。唔好貼喺 chat 或者任何其他地方。
  4. 每部新機只要開 app 條 link，再喺呢度貼一次。
進度

恢復同備份

同步會自動將進度、練習答案同每日備份寫入私人 repo。新機貼好 token 之後撳「恢復進度」，就會攞返 repo 入面最新嗰份。

安裝

放落主畫面或者桌面

Chrome／Edge：網址列右邊個「安裝」圖示。iPhone／iPad Safari：分享 › 加至主畫面。Mac Safari：檔案 › 加至 Dock。裝好之後冇網都開得。
